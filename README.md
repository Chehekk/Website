 YouTube Homepage Clone
This project is a static clone of the YouTube homepage created using only HTML and CSS. It replicates the layout, design elements, and basic structure of the original site without any functionality or interactivity. The clone includes:
- A responsive navigation bar with logo, search bar, and icons
- A sidebar menu with common YouTube sections
- A grid layout showcasing video thumbnails with titles and channel info
- Clean and organized semantic HTML structure
- Modern CSS styling with Flexbox and Grid for layout control
- Responsive design optimized for different screen sizes
- This project helped strengthen my front-end development skills, especially in layout design and responsive styling using pure HTML and CSS.
